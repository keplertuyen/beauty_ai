# Bugfix Review

## Checklist
- [ ] Reproduction test existed and failed before the fix.
- [ ] Root cause documented (not just the symptom).
- [ ] Fix is the smallest safe change; blast radius stated.
- [ ] Regression tests for "unchanged behavior" are green.
- [ ] No acceptance test was weakened to pass the fix.
- [ ] Traceability updated; rollback noted.
