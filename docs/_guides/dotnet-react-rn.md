# .NET + React + React Native pilot

## First run

```bash
npm install
./scripts/dev
```

## API URL contract

- Browser default: `http://localhost:5000` (API) và `http://localhost:5173` (Frontend).
- Mobile React Native nằm trong `apps/mobile`: chỗ dành sẵn cho V2.
